# Inventory-Mangment-System

##Introduction

This Inventory Managment System is an application is a C++ design to help employees manage the warehouse stock. Allowing users to add, remove, update, seach and view the product information. Keeping track the quantity, id number and price.

This was built to strengthen my understanding of C++ programming, object-oriented, data structure, file handling, and software development practices.

##Features

- Add product
- remove product
- update information
- searching product
- display information
- track quantity
- detect low stock

##Technology

- C++
- File I/O
- Object-Oriented Programming
- Data Structure
